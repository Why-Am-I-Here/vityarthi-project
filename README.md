## VITYARTHI-PROJECT
Vityarthi project for BTech CSE Semester 1.
Reg No. : 26BAI10949

# Needed Modules/Libraries:
- Python 3.14.7
- Random (No need to install as it is a library included inside Python)
  
# How to use:
- Keep all the files in a single folder to let the code access different functions from different files.
- Start the file "terminal.py".
- Enter 1 to Encrypt a string or, Enter 2 to decrypt a string.
- Outputs the final encrypted/decrypted text.

# Testing Instructions
To ensure all modules are functioning correctly, this project includes automated unit tests using Python's built-in `unittest` framework.
1. Open your terminal in the project directory.
2. Run the following command:
   `python -m unittest test_project.py`
3. The terminal will output `OK` if all string manipulation logic is functioning as expected.
